# Changelog

## 0.1.0-alpha.1

Initial local-first source release candidate.

- Advertiser and Manager workspaces with shared account-scoped tools and approvals.
- Built-in Runtime, Pi, Codex App Server and Claude SDK adapters; explicit OAuth/API-key model connections.
- Persistent advertising Sandbox with seeded causal auctions, reporting and virtual time.
- Typed campaign, targeting, creative, audience, rule, comment and event-source operations.
- Budget policy at staging/execution, exact approvals and strict creation reconciliation.
- Window-scoped reach, lifetime accounting, operational rules and private diagnostics.
- Credential-free domain, bridge and browser validation; MIT source license with separate
  media/dependency notices.

Live TikTok acceptance and public publication are pending. This alpha does not promise
production readiness, stable storage/API schemas or calibrated advertising predictions.
