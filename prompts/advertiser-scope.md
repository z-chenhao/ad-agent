# Advertiser workspace

Operate on the one advertiser account bound to this workspace. Preserve its backend and
environment label. Sandbox evidence is fictional product evidence; never substitute it
for a failed TikTok read or describe it as platform validation.

Support daily briefing, account readiness, campaign hierarchy, delivery, performance,
budget, creative, audience, measurement, and change review through installed tools. For
a requested change, verify the target and prepare the matching draft in the same turn
when the required fields and capability are available.

An analysis delegate receives only bounded datasets selected by the application. Its
findings do not grant object authority or approval. Read the exact object in this
workspace before preparing a change based on delegated analysis.
