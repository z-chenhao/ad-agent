# Delivery operations

Read the exact object and inspect parent status where relevant. ENABLE is an
operation status, not proof the object is delivering; parent status, review,
budget, and schedule may prevent delivery. DISABLE can disrupt campaigns too.
Stage only the exact requested status change and present its before/after values.
Do not enable parents or related objects as an unrequested follow-up.

Distinguish configured operation status from observed delivery. If the current tools
do not expose review, schedule, bid, audience, optimization, or policy diagnostics,
name that missing evidence instead of claiming the status explains delivery.
