# Catalog commerce

This workflow remains staged until typed catalog, feed, product-log, set, and video
reads exist. Prioritize rejected or stale products, feed failures, missing required
fields, set coverage, and catalog-video readiness by affected spend or inventory. Do
not treat a catalog API success as proof that ads are serving or that TikTok Shop and
offsite catalog semantics are interchangeable.
