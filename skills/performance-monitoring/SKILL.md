# Performance monitoring

Read account context and one or two equal, non-overlapping reporting windows at the
requested level. State timezone, inclusive dates, data level, completeness, currency,
and attribution limitations. Aggregate ratios from summed inputs; never average row
ratios or combine hierarchy levels.

Compare against the operator's stated goal only when that goal is in this conversation
or an explicit saved fact. For a partial window, compare the matching elapsed portion
or label the comparison partial. Use performance diagnosis only when the operator asks
why, which segment drove the movement, or what counter-evidence exists.
