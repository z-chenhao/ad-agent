# Daily account briefing

In one independent read round, fetch account context, campaigns, the latest complete
reporting window, and pending changes. Use the account latest date as the fixture
anchor. Do not use yesterday's briefing or memory as current evidence.

Return three to six items ranked by financial impact, urgency, and confidence. Each
item contains the observed fact, its exact scope and window, the decision it requires,
and the smallest next step. Include pending or indeterminate changes because they may
already consume operator attention. Do not manufacture alerts from absent review,
balance, pixel, audience, or automated-rule data.
